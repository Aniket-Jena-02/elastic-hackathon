# "Dilli Safar" — The Tourist & First-Timer Guide
The Problem: The Delhi Metro map looks like a giant bowl of colorful spaghetti to tourists, students new to the city, or elderly commuters. Navigating interchanges can cause massive anxiety.
The Solution: A simplified, visual-first navigator designed for stress-free travel.

Visual Interchange Walkthroughs: Instead of just text, it uses a step-by-step UI showing visual landmarks within major stations (e.g., "Follow the purple footsteps on the floor for the Magenta line interchange").

Monuments by Metro: A curated exploration mode where users select historical spots (Qutub Minar, Red Fort, Connaught Place) and the app builds the perfect transit route, complete with the best exit gates and walking paths.

Offline Mode: A lightweight, heavily cached version of the route planner because cellular network signals frequently drop underground on lines like the Yellow or Magenta lines.
